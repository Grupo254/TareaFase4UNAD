- Descripción del proyecto
Este proyecto consiste en el desarrollo de un sistema orientado a objetos que permite gestionar clientes, servicios y reservas para la empresa Software FJ.
El sistema está diseñado para ser estable, robusto y tolerante a errores, implementando manejo avanzado de excepciones y registro de eventos mediante logs.

Características principales

Programación orientada a objetos (POO)
Uso de clases abstractas, herencia y polimorfismo
Manejo de excepciones personalizadas
Validación de datos
Registro de errores en archivo de logs
Simulación de operaciones reales (casos válidos e inválidos)
Trabajo colaborativo usando Git y GitHub

Estructura del proyecto

- "cliente.py" → Gestión de clientes
- "servicio.py" → Definición de servicios
- "reserva.py" → Gestión de reservas
- "excepciones.py" → Manejo de errores
- "logger.py" → Registro de eventos
- "main.py" → Ejecución del sistema

Ejecución del programa

Para ejecutar el sistema, usar el siguiente comando:
python main.py

Tecnologías utilizadas
- Python
- Git

Conclusión

Este proyecto permitió aplicar los conceptos basicos y fundamentales de la programación orientada a objetos, así como el manejo adecuado de errores para garantizar la estabilidad del sistema en general.
